# Como Criar um Evento

Os **eventos** no Mapa da Cultura são atividades culturais como shows, espetáculos, exposições, festivais, oficinas e outras manifestações artísticas.

## 📝 Passo a Passo

### 1. Acessar o Menu de Eventos
- Faça login na plataforma
- Clique em **"Eventos"** no menu principal
- Selecione **"Criar Novo Evento"**

### 2. Informações Básicas

**Nome do Evento**
```
Exemplo: "Festival de Jazz de Inverno 2024"
```

**Tipo de Evento**
- Show/Apresentação Musical
- Peça Teatral
- Exposição
- Festival
- Oficina/Workshop
- Palestra/Mesa Redonda
- Cinema/Audiovisual
- Dança/Espetáculo
- Literatura/Sarau
- Evento Gastronômico
- Manifestação Popular

**Linguagem Artística**
- Música
- Teatro
- Dança
- Artes Visuais
- Cinema e Audiovisual
- Literatura
- Circo
- Cultura Popular
- Múltiplas linguagens

### 3. Data e Horário

**Tipo de Programação**
- **Evento Único**: Data e horário específicos
- **Temporada**: Várias apresentações ao longo de um período
- **Festival**: Múltiplos dias com programação variada

**Configuração de Datas**
```
Data de Início: 15/07/2024
Data de Término: 18/07/2024
Horário: 19h30 às 22h00
```

**Recorrência** (se aplicável)
- Diário
- Semanal  
- Mensal
- Datas específicas

### 4. Local e Endereço

**Tipo de Local**
- Presencial
- Online/Virtual
- Híbrido (presencial + online)

**Para Eventos Presenciais**
- Nome do espaço
- Endereço completo
- Referências de localização
- Informações de acessibilidade

**Para Eventos Online**
- Plataforma utilizada (Zoom, YouTube, etc.)
- Link de acesso
- Instruções especiais

### 5. Descrição do Evento

**Sinopse** (máx. 400 caracteres)
> Descrição breve para listagens e redes sociais

**Descrição Completa**
- Conceito do evento
- Programação detalhada
- Artistas/palestrantes participantes
- Público-alvo
- Objetivos e proposta artística

**Classificação Etária**
- Livre
- 10 anos
- 12 anos
- 14 anos
- 16 anos
- 18 anos

### 6. Informações de Acesso

**Tipo de Entrada**
- Gratuita
- Paga
- Meia-entrada disponível
- Convite

**Valores** (se pago)
```
Inteira: R$ 30,00
Meia-entrada: R$ 15,00
Lote promocional: R$ 20,00
```

**Capacidade do Local**
```
200 pessoas
```

**Vendas/Reservas**
- Local de venda
- Plataformas online
- Telefones para reserva
- Instruções especiais

## 🎨 Materiais de Divulgação

### Imagens
- **Cartaz Principal**: Formato vertical (recomendado: 1080x1350px)
- **Banner**: Formato horizontal (recomendado: 1920x1080px)
- **Fotos do Evento**: Múltiplas imagens para galeria

### Vídeos
- Trailer/teaser
- Making of
- Apresentações anteriores

### Textos
- Release para imprensa
- Biografia dos artistas
- Informações técnicas

## 👥 Equipe e Participantes

### Organização
- **Produtor Responsável**
- **Direção Artística**
- **Coordenação Geral**
- **Assessoria de Imprensa**

### Artistas/Palestrantes
Para cada participante, adicione:
- Nome artístico/profissional
- Biografia resumida
- Função no evento
- Redes sociais
- Material de divulgação

### Equipe Técnica
- Sonorização
- Iluminação
- Cenografia
- Registro audiovisual

## 🔧 Configurações Avançadas

### Inscrições/Reservas
- **Sistema de Inscrição**: Ative se necessário
- **Formulário Personalizado**: Colete informações específicas
- **Lista de Espera**: Para eventos com capacidade limitada
- **Confirmação de Presença**: Para controle de público

### Tecnologia

## 📱 Divulgação e Promoção

### Redes Sociais
- Configure hashtags oficiais
- Prepare conteúdo para Instagram, Facebook, Twitter
- Programe posts de divulgação

### Parcerias
- Espaços culturais
- Coletivos artísticos
- Mídia especializada
- Influenciadores culturais

### Assessoria de Imprensa
- Lista de contatos de mídia
- Press kit completo
- Agendamento de entrevistas

## 📊 Acompanhamento

### Métricas
- Visualizações da página
- Inscrições/vendas
- Compartilhamentos
- Engajamento nas redes

### Relatórios
- Público presente
- Avaliações do evento
- Retorno de mídia
- Relatório financeiro

## 💡 Dicas Importantes

### ✅ Boas Práticas
- Publique com antecedência mínima de 30 dias
- Use imagens de alta qualidade
- Mantenha informações sempre atualizadas
- Responda rapidamente às dúvidas do público
- Considere diferentes tipos de público

### ⚠️ Atenção
- Confirme disponibilidade do local antes de publicar
- Verifique autorizações necessárias (direitos autorais, alvará)
- Tenha plano B para eventos ao ar livre
- Mantenha contato atualizado para emergências

## 🔄 Durante e Após o Evento

### Durante
- Faça check-in do público
- Registre o evento (fotos/vídeos)
- Monitore redes sociais
- Colete feedback dos participantes

### Após
- Publique fotos e vídeos
- Atualize status do evento
- Compartilhe resultados
- Planeje próximas edições
