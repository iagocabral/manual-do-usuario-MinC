# Como Criar uma Oportunidade

Uma **oportunidade** no Mapa da Cultura representa editais, chamadas públicas, concursos, residências artísticas, bolsas e outras formas de fomento cultural.

## 📝 Passo a Passo

### 1. Acessar o Menu de Oportunidades
- Faça login na plataforma
- Clique em **"Oportunidades"** no menu principal
- Selecione **"Criar Nova Oportunidade"**

### 2. Informações Básicas
Preencha os campos obrigatórios:

**Título da Oportunidade**
```
Exemplo: "Edital de Fomento à Música Independente 2024"
```

**Tipo de Oportunidade**
- Edital/Chamada Pública
- Concurso
- Prêmio
- Residência Artística
- Bolsa/Auxílio
- Oficina/Workshop
- Outros

**Área Cultural**
- Música
- Teatro
- Dança
- Cinema e Audiovisual
- Literatura
- Artes Visuais
- Cultura Popular
- Patrimônio Cultural
- Múltiplas áreas

### 3. Descrição Detalhada

**Resumo** (máx. 400 caracteres)
> Descrição breve que aparecerá nas listagens

**Descrição Completa**
- Objetivos da oportunidade
- Público-alvo
- Critérios de participação
- Benefícios oferecidos

### 4. Configurações de Prazo

**Data de Abertura**
> Quando as inscrições começam

**Data de Encerramento**
> Prazo final para inscrições

**Data de Divulgação do Resultado**
> Quando os selecionados serão anunciados

### 5. Critérios e Requisitos

**Requisitos de Participação**
- Faixa etária
- Localização geográfica
- Experiência prévia
- Documentação necessária

**Critérios de Avaliação**
- Qualidade artística
- Viabilidade do projeto
- Relevância cultural
- Impacto social

### 6. Recursos e Benefícios

**Valor do Investimento**
```
R$ 50.000,00 por projeto selecionado
```

**Quantidade de Vagas**
```
10 projetos serão contemplados
```

**Benefícios Adicionais**
- Mentoria especializada
- Divulgação institucional
- Espaços para apresentação
- Material de apoio

## 📋 Documentos Necessários

### Para Inscrições
Especifique quais documentos os candidatos devem anexar:

- [ ] Ficha de inscrição preenchida
- [ ] Projeto detalhado (máx. 10 páginas)
- [ ] Portfólio ou material de apoio
- [ ] Orçamento detalhado
- [ ] Cronograma de execução
- [ ] Currículo do proponente
- [ ] Documentos pessoais
- [ ] Comprovante de endereço

## 🔧 Configurações Avançadas

### Formulário de Inscrição
- Configure campos personalizados
- Defina campos obrigatórios
- Organize seções por categoria

### Sistema de Avaliação
- **Comissão Avaliadora**: Defina quem irá avaliar
- **Critérios de Pontuação**: Estabeleça pesos para cada critério
- **Fases de Avaliação**: Configure etapas (habilitação, avaliação, resultado)

### Comunicação
- **E-mails Automáticos**: Configure notificações para inscritos
- **Mensagens do Sistema**: Personalize comunicações internas
- **FAQ**: Adicione perguntas frequentes específicas

## 💡 Dicas Importantes

### ✅ Boas Práticas
- Use títulos claros e descritivos
- Seja específico nos critérios de avaliação
- Defina prazos realistas
- Inclua informações de contato para dúvidas
- Revise todas as informações antes de publicar

### ⚠️ Atenção
- Oportunidades não podem ser excluídas após receberem inscrições
- Alterações significativas devem ser comunicadas aos inscritos
- Mantenha backup de todos os documentos importantes

## 🔄 Após a Publicação

### Gerenciamento
- Acompanhe o número de inscrições
- Responda dúvidas dos interessados
- Monitore o prazo de inscrições

### Avaliação
- Organize a comissão avaliadora
- Distribua as inscrições para análise
- Compile os resultados

### Resultado
- Publique a lista de selecionados
- Envie comunicados aos participantes
- Inicie o acompanhamento dos projetos
