    Problemas Comuns e Soluções

    Guia para resolver os problemas mais frequentes no Mapa da Cultura.

    🔐 Problemas de Acesso

    ❌ "E-mail ou senha incorretos"

    Possíveis causas: - Erro de digitação - Conta não confirmada - Senha alterada recentemente

    Soluções: 1. Verifique se o Caps Lock está desligado 2. Use "Esqueci minha senha" para redefinir 3. Confirme seu e-mail se ainda não o fez 4. Tente fazer login com CPF/CNPJ ao invés do e-mail

    ❌ "Conta não encontrada"

    Possíveis causas: - E-mail digitado incorretamente - Cadastro não finalizado - Conta removida por inatividade

    Soluções: 1. Verifique a grafia do e-mail 2. Tente diferentes variações do seu e-mail 3. Refaça o cadastro se necessário

    ❌ "Acesso negado"

    Possíveis causas: - Conta suspensa - Problemas de moderação - Violação de termos de uso

    Soluções: 1. Entre em contato com o suporte 2. Verifique e-mails sobre suspensão 3. Aguarde análise da moderação

    📝 Problemas com Formulários

    ❌ "Erro ao salvar informações"

    Possíveis causas: - Conexão instável - Campos obrigatórios em branco - Limite de caracteres excedido - Formato de dados incorreto

    Soluções: 1. Verifique sua conexão com a internet 2. Preencha todos os campos marcados com * 3. Respeite o limite de caracteres indicado 4. Use formatos corretos (CPF: 000.000.000-00) 5. Salve em rascunho antes de enviar

    ❌ "Não consigo anexar arquivos"

    Possíveis causas: - Arquivo muito grande (>10MB) - Formato não suportado - Nome com caracteres especiais - Cache do navegador

    Soluções: 1. Comprima o arquivo ou reduza a qualidade 2. Use formatos aceitos: PDF, DOC, DOCX, JPG, PNG 3. Renomeie sem acentos ou caracteres especiais 4. Limpe o cache do navegador 5. Tente outro navegador

    ❌ "Campos não estão sendo salvos"

    Possíveis causas: - JavaScript desabilitado - Navegador desatualizado - Extensões interferindo

    Soluções: 1. Habilite JavaScript no navegador 2. Atualize para a versão mais recente 3. Desative extensões temporariamente 4. Use modo privado/anônimo

    🎪 Problemas com Oportunidades

    ❌ "Oportunidade não aparece na busca"

    Possíveis causas: - Ainda em moderação - Informações incompletas - Filtros de busca muito específicos - Status incorreto

    Soluções: 1. Aguarde aprovação da moderação (até 48h) 2. Complete todas as informações obrigatórias 3. Use termos de busca mais amplos 4. Verifique se o status está como "Publicado"

    ❌ "Não consigo editar após publicar"

    Possíveis causas: - Já há inscrições recebidas - Prazo de edição expirado - Permissões insuficientes

    Soluções: 1. Algumas edições são limitadas após inscrições 2. Entre em contato com suporte para alterações críticas 3. Use a área de "Comunicados" para informações adicionais

    ❌ "Inscrições não estão chegando"

    Possíveis causas: - Formulário mal configurado - E-mails indo para spam - Problemas no sistema

    Soluções: 1. Teste o formulário você mesmo 2. Verifique configurações de notificação 3. Adicione domínio oficial à lista de remetentes seguros 4. Reporte ao suporte se persistir

    📅 Problemas com Eventos

    ❌ "Evento não aparece no calendário"

    Possíveis causas: - Data incorreta - Status como rascunho - Problemas de sincronização - Evento privado

    Soluções: 1. Verifique se a data está correta 2. Altere status para "Publicado" 3. Aguarde alguns minutos para sincronização 4. Confirme configurações de privacidade

    ❌ "Imagens não carregam"

    Possíveis causas: - Arquivo corrompido - Formato não suportado - Tamanho excessivo - Conexão lenta

    Soluções: 1. Use JPG ou PNG de boa qualidade 2. Redimensione para máximo 1920x1080px 3. Comprima se necessário 4. Tente fazer upload em horário de menor tráfego

    ❌ "Não consigo cancelar evento"

    Possíveis causas: - Já há participantes inscritos - Data muito próxima - Política da plataforma

    Soluções: 1. Use "Comunicados" para avisar sobre cancelamento 2. Entre em contato com o suporte 3. Marque como "Cancelado" no status

    🏛️ Problemas com Espaços

    ❌ "Localização não é encontrada"

    Possíveis causas: - Endereço incompleto - CEP incorreto - Local muito novo - Coordenadas erradas

    Soluções: 1. Digite endereço completo com número 2. Verifique CEP nos Correios 3. Use referências próximas conhecidas 4. Insira coordenadas manualmente se necessário

    ❌ "Não consigo vincular eventos ao espaço"

    Possíveis causas: - Permissões insuficientes - Espaço não aprovado - Configuração incorreta

    Soluções: 1. Verifique se você é administrador do espaço 2. Aguarde aprovação do espaço 3. Use a opção "Selecionar espaço existente"

    📱 Problemas de Navegação

    ❌ "Site carrega lentamente"

    Possíveis causas: - Conexão instável - Muitas abas abertas - Cache lotado - Horário de pico

    Soluções: 1. Teste sua velocidade de internet 2. Feche abas desnecessárias 3. Limpe cache e cookies 4. Acesse em horários alternativos

    ❌ "Botões não funcionam"

    Possíveis causas: - JavaScript desabilitado - Conflito de extensões - Navegador incompatível

    Soluções: 1. Habilite JavaScript 2. Desative extensões bloqueadoras 3. Use Chrome, Firefox ou Safari atualizados 4. Recarregue a página (Ctrl+F5)

    ❌ "Layout quebrado/desorganizado"

    Possíveis causas: - CSS não carregou - Zoom inadequado - Extensões interferindo - Navegador desatualizado

    Soluções: 1. Recarregue a página 2. Ajuste zoom para 100% 3. Desative extensões de tema 4. Atualize o navegador

    📧 Problemas de Comunicação

    ❌ "Não recebo notificações por e-mail"

    Possíveis causas: - E-mail na pasta spam - Configurações desativadas - Provedor bloqueando - E-mail incorreto no perfil

    Soluções: 1. Verifique pasta de spam/lixo eletrônico 2. Adicione cultura.gov.br aos contatos seguros 3. Ative notificações nas configurações 4. Atualize e-mail no perfil

    ❌ "Mensagens não chegam aos destinatários"

    Possíveis causas: - Usuário bloqueou comunicações - Limite de mensagens atingido - Conteúdo considerado spam

    Soluções: 1. Verifique se não foi bloqueado 2. Aguarde para enviar mais mensagens 3. Evite links e linguagem promocional excessiva 4. Use canais alternativos de contato

    🔧 Quando Entrar em Contato com o Suporte

    Situações que exigem suporte:

    • Problemas persistentes após tentar soluções
    • Perda de dados importantes
    • Suspeita de atividade maliciosa
    • Dúvidas sobre políticas da plataforma
    • Problemas de pagamento ou financeiros
    • Solicitações de exclusão de conta

    Informações para incluir no contato:

    1. Descrição detalhada do problema
    2. Passos que levaram ao erro
    3. Mensagens de erro exatas
    4. Navegador e versão utilizados
    5. Prints da tela se relevante
    6. E-mail cadastrado na plataforma
